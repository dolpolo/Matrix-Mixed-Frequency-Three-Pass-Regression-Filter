# Matrix MF–TPRF — Replication cookbook

**Paper:** *Matrix Three-Pass Regression Filter: A Nowcasting Framework for Mixed-Frequency Multidimensional Data*  
**Authors:** Matteo Barigozzi (University of Bologna), Davide Delfino (Aarhus University), Massimiliano Marcellino (Bocconi University)  
**Maintainer:** Davide Delfino · Aarhus University, Department of Economics · **davide.delfino@econ.au.dk**

## Requirements and installation

R **4.3+** is recommended. Run all commands from the package root (containing
`run_all.R`). Install the CRAN dependencies listed in `install_dependencies.R`:

```bash
Rscript install_dependencies.R
```

Models use the supplied EA–MD–QD workbooks under `data/raw/` and
`data/transformed/`, and the **information set** in
`data/information_set/selected_variables_50.csv` (35 monthly, 15 quarterly
indicators, eight countries). Input selection is not re-executed. Data source:
Barigozzi, Lissona and Tonni, EA–MD–QD, [Zenodo](https://zenodo.org/records/14565823),
[project page](https://www.barigozzi.eu/EA.html).

## One-command replication

```bash
Rscript run_all.R
```

The default workflow checks input files, estimates Matrix MF–TPRF with **both
aggregate-target and unit-target proxies**, VEC-C, VEC-P, DFM and the EA vector
model, generates the approved paper figures and tables, publishes the **mandatory
asymptotic-normality histograms and Q–Q plots** (row and column loadings), and
validates the output manifest. Saved AN results are reused if their figures
already exist. **Forecasting Monte Carlo is not run by default.**

For selected tasks:

```bash
Rscript run_all.R check       # Verify the 50-indicator dataset and required workbooks
Rscript run_all.R empirical   # Estimate empirical models; no paper-output collection
Rscript run_all.R outputs     # Paper outputs + mandatory AN figures from saved results
Rscript run_all.R loading     # Generate or reuse loading-structure Figure 2
Rscript run_all.R an          # Generate or reuse mandatory Pass 1 AN figures
```

The forecasting Monte Carlo code **is preserved**, but must be launched explicitly:

```bash
Rscript run_model.R forecast_mc
```

You can run each empirical component separately, for example:

```bash
Rscript run_model.R matrix       # Aggregate-target proxy
Rscript run_model.R matrix_unit  # Unit-target proxy
Rscript run_model.R vecc
Rscript run_model.R vecp
Rscript run_model.R dfm
Rscript run_model.R ea
```

## Independent paper-output scripts

Each script in `scripts/03_outputs/` can be run independently after its inputs
have been estimated, e.g. `Rscript scripts/03_outputs/07_country_nowcasts.R`.

| Script | Reproduces |
|---|---|
| `01_empirical_comparison.R` | Main empirical RMSFE/DM table |
| `02_loading_wald.R` | Loading-structure Figure 2 and main Wald table |
| `03_predictor_panel.R` | Predictor coverage and unavailability tables |
| `04_matrix_factor.R` | Static factor, column loadings, 8×50 loading map, row-loading table |
| `05_ea_factor.R` | Matrix-versus-vector EA factors and in-sample fit |
| `06_dfm_comparison.R` | DFM RMSFE and relative RMSFE table |
| `07_country_nowcasts.R` | Eight separate country plots and post-Covid 4×2 figure |
| `08_proxy_design.R` | Unit-target versus aggregate-target and DFM table |
| `09_forecast_wins.R` | Country- and forecast-level win shares |
| `10_ea_nowcasts.R` | EA nowcast plot and Matrix/VEC-C RMSFE table |

## Output locations

| Directory | Contents |
|---|---|
| `results/empirical/` | Model estimates and saved real-time summaries |
| `results/monte_carlo/` | Saved simulation results (loading, AN, and optional forecasting) |
| `results/paper/main/figures/`, `tables/` | Final main-text R-generated assets |
| `results/paper/appendix/figures/`, `tables/` | Final appendix R-generated assets |
| `results/diagnostics/asymptotic_normality/` | Mandatory row/column histograms and Q–Q plots |
| `results/audit/` | Numeric CSVs and audit traces, not publication assets |

Expected output paths and producing scripts are enumerated in
`config/output_manifest.csv`; `run_all.R outputs` validates every listed file.

**Scope exception:** Manuscript Figure 1 is a conceptual graphic, while the
forecasting Monte Carlo Table 1 / Figure 3 are **not** regenerated by the default
runner, by design. Their simulation source remains available.

**Saved-result note:** This lightweight distribution includes the necessary R
source code, complete input workbooks, existing publication figures/tables, and
cached AN and loading-structure diagnostics. Large empirical `.rds` estimation
caches are not bundled to keep the download manageable: `Rscript run_all.R`
recreates them. To run `Rscript run_all.R outputs` without re-estimation,
copy the `results/empirical/` RDS results from your previously completed run
into this package first.

**Validation status:** Static paths and included publication outputs were
verified, but full R execution was unavailable in the packaging environment.
